# Birthday Interactive Game 🎂

A Next.js-based interactive birthday story game with mini-games and memories.

## Features
- PIN-protected entry
- Interactive mini-games
- Photo memory slideshow
- Background music with mute control
- Smooth animations with Framer Motion
- Mobile-first design

## Tech Stack
- Next.js 14 (App Router)
- React 18
- Framer Motion
- Tailwind CSS
